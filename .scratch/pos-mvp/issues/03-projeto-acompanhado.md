# 03: ProjetoAcompanhado (fixar / não acompanhar / excluir)

**What to build:** Permitir fixar, acompanhar, deixar de acompanhar e excluir projetos (spec 4.1.1), separando descoberta diária de acompanhamento contínuo, e detectar releases/mudanças relevantes sem noticiar cada commit.

**Blocked by:** None (can start immediately)

**Status:** needs-triage

- [ ] CRUD de projetos acompanhados no admin, por fonte.
- [ ] Fixar/excluir reflete na seleção das curadorias.
- [ ] Release/mudança relevante gera sinal, sem notícia por commit/README.
