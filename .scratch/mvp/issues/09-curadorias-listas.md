# 09: Curadorias (listas) e páginas derivadas

**What to build:** Cada curadoria é **uma postagem por período** com itens estruturados; `quantidade_itens` configurável (padrão 1, teto 5); frequência configurável (padrão GitHub diário, HF semanal); páginas por item como **visões derivadas** da mesma versão (sem aprovação própria); aviso de curadoria própria; contabilização por postagem/execução.

**Blocked by:** 08, 04

**Status:** ready-for-agent

- [ ] Gerar uma curadoria GitHub e uma HF com quantidade de itens configurável.
- [ ] Cada item abre como página derivada, sem versão/aprovação própria.
- [ ] Custo agregado à postagem/execução, sem dupla contagem.
- [ ] A seção declara curadoria própria e nunca ranking oficial de terceiros.
